## 🚀 Projetos em Destaque

### 🧾 [Python Fiscal — NF-e / SEFAZ](https://github.com/WendeNJ/PYTHONFISCAL)
> Aplicação em Python para consulta, tratamento e armazenamento de documentos fiscais eletrônicos.

- Consulta de **NF-e destinadas a um CNPJ** usando `NFeDistribuicaoDFe`
- Comunicação direta com a **SEFAZ via SOAP 1.2 + mTLS** com certificado digital
- Controle de **NSU e paginação** para sincronização de documentos
- Decodificação de documentos `Base64 + GZIP` e processamento de XML
- Manifestação do destinatário com eventos assinados digitalmente
- Aplicação web construída com **Python, Flask e SQLite**

`Python` `Flask` `SOAP` `XML` `SEFAZ` `SQLite` `Certificado Digital`
